# 🍳 Armazém das Receitas

Uma aplicação web completa e responsiva para catálogo, busca e gerenciamento de receitas culinárias, integrada com Firebase Auth e Firestore.

## 🚀 Funcionalidades

- **Catálogo Dinâmico:** Mais de 30 receitas organizadas por categorias (Café da Manhã, Almoço/Jantar e Sobremesas).
- **Busca e Filtros:** Pesquisa em tempo real por nome do prato ou ingredientes, além de filtros por tempo de preparo.
- **Autenticação Firebase:** Login com Email/Senha, Google ou Acesso Convidado.
- **Painel de Administração:** Permite criar novas receitas e excluir itens (CRUD) direto pela interface para administradores.
- **Ajuste de Porções:** Calculadora que ajusta automaticamente a quantidade de ingredientes com base nas porções desejadas.
- **Favoritos Local:** Salve suas receitas preferidas para acesso rápido.
- **Modo Impressão:** Formatação pronta para imprimir a ficha da receita.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 & JavaScript (ES6+):** Estrutura e lógica da aplicação.
- **Tailwind CSS:** Estilização responsiva e moderna via CDN.
- **FontAwesome:** Ícones de interface.
- **Firebase Authentication & Firestore:** Autenticação de usuários e banco de dados em tempo real.
- **Unsplash API/Images:** Imagens de alta qualidade representativas de cada receita.
